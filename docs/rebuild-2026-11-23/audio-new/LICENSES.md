# Lizenz / Herkunft der Audio-Dateien

**Urheber:** Oruci Sabahudin
**Projekt:** Kagewell (ehem. Barrel Ninja)
**Umfang:** alle Dateien in diesem Ordner (`*.ogg`, `*.m4a`, `*.mp3`), die WAV-Master in
`/workspace/barrel-ninja-sfx/new/wav/` sowie das Generator-Skript `generate_new.py`.

## Herkunft

- Sämtliche Klänge wurden vollständig prozedural per Code erzeugt (`generate_new.py` plus die
  Klangmodelle aus `../audio/generate.py`, Python mit numpy/scipy): Rauschgeneratoren, Filter,
  Sinus-/Modal-/FM-Synthese, Karplus-Strong-Saitensynthese, additive Flötensynthese und
  Faltungshall mit synthetisch berechneten Impulsantworten.
- Es wurden **keine Samples, Loops, Aufnahmen oder Impulsantworten Dritter** verwendet.
- Keine Übernahme von Melodien, Klängen oder Motiven aus anderen Spielen.
  Die verwendete pentatonische In-Skala auf D (D–Eb–G–A–Bb) ist eine traditionelle, gemeinfreie Tonleiter.
- Werkzeuge (numpy, scipy, soundfile, pyloudnorm, matplotlib, ffmpeg) wurden nur zur Berechnung
  und Kodierung genutzt; sie übertragen keine Rechte oder Lizenzpflichten auf die erzeugten Audiodateien.

## Nutzung

Die Dateien sind Eigentum von Oruci Sabahudin und dürfen frei verwendet, verändert, weitergegeben und
kommerziell genutzt werden – in Kagewell und in jedem anderen Projekt. Keine Namensnennung erforderlich.
